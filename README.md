# Skills Jurídicas com IA

Este repositório contém **415 skills jurídicas** criadas para auxiliar advogados na elaboração de peças, contratos, análises e muito mais, utilizando Inteligência Artificial.

As skills estão organizadas em 23 áreas do Direito e vêm com descrições, momentos ideais de uso, dicas e o **prompt exato** que você deve utilizar na sua IA favorita.

## 🚀 Como instalar e usar

Estas skills podem ser usadas tanto em assistentes de IA baseados em chat (como o Claude e o ChatGPT) quanto no seu assistente local (Antigravity).

### 🤖 Instalação no Claude (ou ChatGPT)

Você tem duas formas principais de utilizar no Claude:

#### Método 1: Uso Direto (Mais simples)
1. Navegue pelas pastas deste repositório e encontre a skill desejada (ex: `penal-penal/01-resposta-a-acusacao.md`).
2. Abra o arquivo e copie todo o texto que está na seção **Prompt**.
3. Cole no Claude ou ChatGPT e adicione as informações do seu caso concreto.
4. A IA irá gerar a peça seguindo exatamente a estrutura e regras da skill.

#### Método 2: Via Projetos (Apenas Claude Pro/Team)
1. Crie um novo "Project" no Claude.
2. Na seção de **Knowledge** (Conhecimento), faça o upload dos arquivos `.md` das áreas que você mais atua.
3. Nas "Custom Instructions" do projeto, escreva: *"Você tem acesso a diversas skills jurídicas no seu Knowledge. Sempre que eu pedir uma peça, consulte o arquivo correspondente e siga o framework e as regras exigidas na skill."*
4. Agora basta pedir no chat do projeto: *"Faça uma resposta à acusação para o caso X"*.

### 🚀 Instalação no Antigravity

Como o Antigravity é o seu agente de IA integrado ao seu sistema, você pode usar estas skills de forma autônoma. 

1. **Clone ou baixe** este repositório para o seu ambiente local onde o Antigravity tem acesso. 
   *(Se você está lendo isso, é provável que a pasta `skills-juridicas-ia` já esteja no seu sistema).*
   
2. **Peça ao Antigravity para utilizar a skill.** Exemplo de prompt para o Antigravity:
   > "Antigravity, por favor, elabore uma Resposta à Acusação. Leia a skill localizada na pasta `skills-juridicas-ia/penal-penal/01-resposta-a-acusacao.md` para entender as regras obrigatórias e o Framework P.A.C.E.F. Aqui estão os dados do caso: [inserir dados]."

3. **Uso Avançado:** Se você usa o sistema modular de skills do Antigravity (com arquivos `SKILL.md`), você pode copiar as pastas destas skills para dentro do seu diretório `.agent/skills/`. Assim, o Antigravity poderá pesquisar e carregar essas diretrizes automaticamente durante o processo de *Intelligent Routing*.
